# Ahmed Precious Mary Portfolio

A personal portfolio for Ahmed Precious Mary, a social media manager, UGC creator, community manager, and virtual assistant based in Nigeria.

The site presents Ahmed's experience, selected work, creative process, production tools, skills matrix, service options, and contact channels in a polished, responsive layout.

## Features

- Responsive desktop and mobile design
- Animated portfolio sections
- Social media and selected work portfolio
- Creative video production process
- Production gear and software overview
- Interactive skills matrix preview
- Project scope builder with email proposal generation
- Direct email, WhatsApp, Instagram, TikTok, and X links
- Downloadable CV

## Built With

- HTML5
- CSS3
- JavaScript
- Vite

## Run Locally

### Requirements

- Node.js 18 or newer
- npm

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
